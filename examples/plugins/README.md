# Example plugins

Copy a folder into the server's plugins directory (`plugins_dir`, default `<data_dir>/plugins`)
and restart the server. See [PLUGINS.md](../../PLUGINS.md) for the format.

| Folder | Adds |
|---|---|
| `openseamap` | OpenSeaMap sea marks as a `direct` overlay (loaded by the browser from tiles.openseamap.org; CC BY-SA, attribution included) and a link to the OpenSeaMap website |

Before you use or ship a plugin, check the tile provider's terms. You are responsible for following them.
